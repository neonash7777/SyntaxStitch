# Manual Test Lab

Launch **Run SyntaxStitch: Manual Test Lab (No Debugger)** to open this folder in an Extension Development Host.

## Fault Injection

The four `fixture` files are stable targets for the steps in [AI_TEST_PROMPT.md](AI_TEST_PROMPT.md).

## Advanced Examples

- [advanced-embedded.html](advanced-embedded.html) combines deeply nested HTML with embedded CSS and JavaScript.
- [advanced-component.tsx](advanced-component.tsx) combines TypeScript delimiters, JSX tags, expressions, callbacks, and template interpolation.
- [advanced-nested.js](advanced-nested.js) stresses nested objects, arrays, callbacks, computed access, and nested template literals.

Use **SyntaxStitch: Inspect Active Document** to compare indexed structures, then delete one opening or closing boundary at a time to exercise repair, pair labels, selection, and folding.
